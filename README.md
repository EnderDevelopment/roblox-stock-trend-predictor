# Roblox Stock Exchange Game

This is a Roblox game that simulates a stock exchange where players can buy and sell stocks, predict trends, and use strategies like buying at the bottom and selling at the top. The game includes client-side scripts for predicting stock trends and implementing buy low sell high strategy, server-side scripts for updating stock prices and handling player transactions, and a module script for initializing the stock exchange and getting current stock prices.

## Install

1. Download the project files from the GitHub repository.
2. Open Roblox Studio.
3. Create a new Roblox game or open an existing one.
4. Place the client script (`StockExchangeClient.lua`) in the StarterPlayerScripts folder.
5. Place the server script (`StockExchangeServer.lua`) in the ServerScriptService folder.
6. Place the module script (`StockExchangeModule.lua`) in the ReplicatedStorage folder.

## Use

1. Start the game in Roblox Studio.
2. Players can use the client-side functions to predict stock trends and implement buy low sell high strategy.
3. The server-side functions will update stock prices and handle player transactions.
4. The module script provides shared functions for initializing the stock exchange and getting current stock prices.
